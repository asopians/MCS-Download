# MCS – Manajemen Channel by Sopian

Unduhan resmi aplikasi **MCS (Manajemen Channel by Sopian)**: kelola banyak channel YouTube sekaligus — Dashboard pendapatan, Analytic, AdSense, Scheduler, Auto Translate, Live Streaming 24 jam, Authenticator 2FA, serta Backup & Import.

> Aplikasi membutuhkan **lisensi aktif**. Pembelian & perpanjangan: **[mcs.sopian.web.id](https://mcs.sopian.web.id)**

## Cara pasang
**Windows:** jalankan `MCS-2.1.1-Setup.exe`. Bila muncul *"Windows protected your PC"*, klik **More info → Run anyway**, lalu ikuti langkah instalasi.

**macOS:** ekstrak zip, seret **Managemen Channel by Sopian.app** ke folder **Applications**. Saat pertama dibuka: klik kanan aplikasi → **Open** (atau *System Settings → Privacy & Security → Open Anyway*).

**Update:** aplikasi yang sudah terpasang memberi tahu bila ada versi baru (tombol ⬆️ Update di sidebar). Data akun, API, jadwal, pengaturan live & lisensi tetap aman setelah update.

## Catatan versi

### 2.1.1 — Live Streaming lebih stabil, update tanpa hentikan live & Scheduler hemat kuota
- Penting – update dari versi 2.1.0: hentikan live terlebih dahulu, lalu pasang update. Akun, API, jadwal, pengaturan live & lisensi tetap aman
- Live Streaming: live tidak lagi gagal dimulai karena judul/deskripsi (tanda < > diganti otomatis, judul maks. 100 & deskripsi maks. 5.000 karakter, termasuk hasil Import Data)
- Live Streaming: nama tab seragam (Live 1, Live 2, dst.) dan nama yang diubah langsung tersimpan; tombol jadwal "Set" kini bernama "Start"
- Update aplikasi: mulai versi berikutnya, update bisa dipasang walau live berjalan; live terputus ±1 menit lalu menyala lagi otomatis dengan judul & metadata yang sama
- Update aplikasi: tidak pernah terpasang sendiri; unduhan & pemasangan hanya saat Anda klik
- Scheduler: lebih hemat kuota; saat kuota YouTube habis, jadwal ditunda bersama dan dicek tiap 30 menit, lalu langsung dipublish begitu kuota pulih
- AdSense: total saldo dijumlahkan dalam Rupiah; akun bermata uang lain tampil terpisah dengan mata uangnya sendiri
- AdSense: email akun kini ikut disamarkan di pesan peringatan saat tombol 👁 Email aktif
- Authenticator: tombol 👁 Nama baru untuk menyamarkan nama akun (hanya 4 huruf terakhir yang tampil, mis. •••••sdas@gmail.com), aman saat layar direkam
- Tampilan: ukuran jendela menyesuaikan layar (laptop kecil, zoom Windows, RDP) dan sidebar otomatis dirapatkan bila layar pendek
- Tampilan: tombol Info Lisensi, Perpanjang & Reset digabung jadi satu tombol 🔑 Lisensi di sidebar
- Tombol 📋 Log baru di sidebar: berisi error & kejadian penting (live gagal/terputus, kuota habis, upload gagal); klik Salin lalu kirim ke admin bila ada masalah
- Error tak terduga dilaporkan otomatis ke developer agar cepat diperbaiki (tanpa data akun, token, atau password)
- Aplikasi tidak lagi macet saat baru dibuka (sebelumnya bisa tidak merespons hingga ±1 menit bila banyak tab Live Streaming)
- Lisensi: tombol "Beli Lisensi" membuka halaman harga di website resmi, dan setelah lisensi terkunci aplikasi langsung menampilkan layar aktivasi saat dibuka ulang
